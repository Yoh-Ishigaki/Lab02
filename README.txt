# program summary

Downloads a set of real records from a public web API, groups and summarizes them, and 
writes the result to a JSON file.

  
## Setup 

    python -m venv .venv 
    source .venv/bin/activate      # Windows: .venv\Scripts\activate 
    pip install -r requirements.txt 
 
## Run 
  
    python  Weather_summary.py 
  
## Program execution result
   
Success: processed 168 valid records and wrote weather_summary.json.
 
## output

Write weather data to a JSON file
